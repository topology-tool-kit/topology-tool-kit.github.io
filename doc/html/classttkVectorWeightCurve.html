Detailed Description

TTK VTK-filter for the computation of vector field weight curves.

Author
Tanner Finken
Josh A. Levine
Date
2024.

This filter takes a 2D vector field as input and computes the number of pairs as a function of weight (i.e. the number of pairs whose simplification weight is higher than a threshold).

These curves provide useful visual clues in order to fine-tune simplification thresholds of a discrete vector field.

Parameters
InputInput Vector Field
OutputTable giving the number of all simplified pairs as a function of weight(simplifying value) (vtkTable)

Related publication
"Localized Evaluation for Constructing Discrete Vector Fields"
Tanner Finken, Julien Tierny, Joshua A. Levine
IEEE VIS 2024.

Online examples:

  • Discrete Vector Field Topology example
