Detailed Description

TTK base class that computes the persistence diagram of a Rips complex of a planar point cloud using a fast, dedicated algorithm.

Author
Mattéo Clémot matte.nosp@m.o.cl.nosp@m.emot@.nosp@m.univ.nosp@m.-lyon.nosp@m.1.fr
Date
January 2024.

This module defines the FastRipsPersistenceDiagram2 class that takes a planar point cloud and computes the persistence diagram of its Rips complex using a geometric-only algorithm based on the computation of the relative neighborhood graph (RNG) and minmax length (MML) triangulations.
